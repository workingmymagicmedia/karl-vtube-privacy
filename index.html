Privacy Policy — Karl’s Vtube Software

Last updated: September 15, 2026

Karl’s Vtube Software is a privately distributed Windows desktop application used by the developer and one invited user for avatar rendering and livestream production.

Camera Access

Karl’s Vtube Software accesses the user-selected camera to provide a live camera source to Snap Camera Kit for real-time Lens rendering. The application is designed so the raw camera is not intentionally displayed in Karl’s interface or sent directly to OBS. OBS receives the guarded Camera Kit Lens-rendered output.

Camera, Microphone, Location, and Media Permissions

The current version requests camera access when needed for avatar rendering. It does not intentionally request microphone, background location, or media-library access. If future functionality requires additional permissions, this policy will be updated before that functionality is used.

Data Stored by Karl’s Vtube Software

Karl’s Vtube Software does not require a Karl user account and does not maintain a Karl-operated remote database of personal information. Application preferences may be stored locally on the user’s computer, including camera selection, Lens identifiers, Face Blend settings, Camera Kit agreement acknowledgement, and other application configuration. If the user chooses to remember Camera Kit configuration, that information is also stored locally on that computer.

Snap Camera Kit

Karl’s Vtube Software uses Snap Camera Kit to load and render Lens Studio Lenses. Camera Kit communicates with Snap services as part of normal operation, including Lens delivery, authentication, diagnostics, usage metrics, and performance information. Snap’s handling of information is governed by Snap’s own terms and privacy practices.

OBS Output

Karl provides a local Browser Source for OBS at a localhost address on the same computer. The OBS output is intended to contain only the Camera Kit Lens-rendered result. If Karl cannot verify that a Lens is active, the output is designed to fail closed rather than intentionally expose the raw camera.

Mix It Up Integration

Karl can optionally receive local costume-change commands from Mix It Up through a localhost-only HTTP interface on the same computer. Karl does not require Mix It Up account credentials and does not receive viewer currency balances, Twitch credentials, or chat history through this integration. The current integration sends Karl only the requested costume/Lens name needed to perform the local costume change.

Mix It Up is a separate third-party application with its own privacy practices. Users who enable Mix It Up are responsible for their configuration of that service.

Sharing of Information

Karl’s Vtube Software does not sell personal information. Karl does not intentionally publish the user’s raw webcam feed to Snapchat or intentionally transmit the raw webcam feed to Mix It Up. Camera Kit-related communications with Snap are subject to Snap’s policies described above.

Distribution

Karl’s Vtube Software is privately distributed for use by the developer and one invited user. It is not generally distributed to the public.

Changes to This Policy

This policy may be updated when Karl’s functionality or third-party integrations materially change. The “Last updated” date above will be revised when changes are published.
