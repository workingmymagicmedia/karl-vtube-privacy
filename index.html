Privacy Policy — Karl’s Vtube Software Last updated: September 15, 2026 Karl’s Vtube Software is a private desktop application used to render an avatar for livestreaming. Camera Access The application accesses the user-selected camera in order to provide a live video stream to Snap Camera Kit for real-time Lens rendering. The application does not include functionality to publish or broadcast the user’s raw webcam feed to Snapchat. Data Collected by Karl’s Vtube Software Karl’s Vtube Software does not require a user account and does not maintain a database of personal information. Camera Kit configuration information, such as Lens identifiers and application settings, may be stored locally on the computer. Snap Camera Kit The application uses Snap Camera Kit. Camera Kit may collect anonymized usage, diagnostic, crash, and performance information as part of its normal operation. Snap’s own privacy practices are governed by Snap’s applicable privacy policies and Camera Kit terms. Camera and Microphone Permissions Camera access is requested only when needed for avatar rendering. Microphone access will only be requested if functionality requiring microphone input is enabled. The application does not request background location access. Sharing of Information Karl’s Vtube Software does not sell personal information. The application does not intentionally provide the user’s webcam stream to other users or publish it to Snapchat. Distribution Karl’s Vtube Software is currently a private application intended for personal use and is not publicly distributed.
